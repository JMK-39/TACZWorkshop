English

- Moved the TACZ Workshop mixin configuration to the resource root and updated its registration path so Mixin can discover it without a mixins/ directory.

- Migrated public build dependencies to their published repository coordinates and removed the need for local copies of those libraries. In-game behavior is unchanged.

简体中文

- 将 TACZ Workshop 的 Mixin 配置文件移至资源根目录并更新注册路径，无需 mixins/ 子目录即可被 Mixin 正确发现。

- 将公开构建依赖迁移到已发布的仓库坐标，不再需要这些库的本地副本。游戏内行为没有变化。
