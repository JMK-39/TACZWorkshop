# TACZ Workshop

> V1.0

## 简体中文

在游戏内制作和维护 TACZ 数据与枪匠工作台配方。

### 核心功能

- 搜索、浏览和编辑枪械、配件、弹药、近战及补给数据。
- 创建、编辑、移除枪匠工作台配方，并管理对应工作台及配方校验。
- 支持带 NBT 的物品选择与处理；可选兼容精妙背包。

### 使用

按 **F6** 进入 TACZ Workshop，分别使用 TACZ 数据编辑器与枪匠工作台配方编辑器。共享数据由服务端应用，保存需要管理权限。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+、Timeless and Classics Zero (TACZ)；可选：Sophisticated Backpacks、Sophisticated Core。

## English

Creates and maintains TACZ data and gunsmith-workbench recipes in-game.

### Features

- Search, browse, and edit firearms, attachments, ammunition, melee, and supply data.
- Create, edit, and remove gunsmith-workbench recipes with workbench routing and validation.
- Handle NBT-bearing items and optionally integrate with Sophisticated Backpacks.

### Usage

Press **F6** and open the TACZ data editor or gunsmith-workbench recipe editor. Shared data is applied server-side, and saving requires administrator permission.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+, Timeless and Classics Zero (TACZ). Optional: Sophisticated Backpacks, Sophisticated Core.
